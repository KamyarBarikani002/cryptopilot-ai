# CryptoPilot AI

دستیار سرمایه‌گذاری/معاملاتی رمزارز. دو بخش داره که هر دو توی یک پنل Streamlit
در دسترسن:

- **اسکنر فیوچرز** (صفحه اصلی): چند ارز پرحجم فیوچرز بایننس رو با ترکیب
  تحلیل تکنیکال (روند + RSI) و فاندامنتال (فاندینگ، Open Interest، شاخص
  ترس‌وطمع) بررسی می‌کنه و فرصت‌های Long/Short با حد سود/ضرر/اهرم/حجم پوزیشن
  پیشنهادی می‌ده. تاریخچه سیگنال‌ها و نرخ برد هم ثبت می‌شه.
- **پرتفوی DCA** (صفحه کناری): هر ماه یه مبلغ ثابت رو بر اساس رژیم بازار بین
  چند ارز تخصیص می‌ده و پوزیشن BTC رو مدیریت می‌کنه.

پنل پشت یک رمز عبور تک‌کاربره‌ست. وضعیت (پرتفوی، تاریخچه سیگنال‌ها، تنظیمات)
توی یک دیتابیس SQLite (`database/cryptopilot.db`) نگه داشته می‌شه، نه فایل
JSON.

## راه‌اندازی اولیه

```bash
pip install -r requirements.txt
python scripts/set_password.py   # یک‌بار، برای تنظیم رمز عبور پنل
./start_panel.sh
```

بعد از اجرا، پنل روی `http://localhost:8501` بالا میاد.

## ساختار

- `dashboard.py` — صفحه اصلی (اسکنر فیوچرز)
- `pages/1_Spot_DCA_Portfolio.py` — صفحه پرتفوی DCA
- `src/auth.py` — لایه ورود؛ `scripts/set_password.py` رمز رو تنظیم می‌کنه
- `src/db/` — مدل‌ها و اتصال دیتابیس (SQLAlchemy + SQLite)
- `src/futures/` — منطق اسکنر فیوچرز
- `src/core/`, `src/portfolio/`, `src/*.py` — منطق پرتفوی DCA
- `src/backtest/` — ابزارهای بک‌تست استراتژی/پرتفوی

## نکات امنیتی

- رمز عبور هیچ‌وقت توی کد یا گیت ذخیره نمی‌شه؛ فقط هش‌ش توی `.env` (که در
  `.gitignore` هست).
- این ابزار فقط از API عمومی (بدون کلید) بایننس و شاخص ترس‌وطمع استفاده
  می‌کنه؛ معامله واقعی رو خودت دستی توی صرافی انجام می‌دی.
